# 🌡️ Monitoramento de Temperatura e Umidade com ESP32-C3

Este projeto consiste em um sistema embarcado de baixo custo para aquisição, processamento e envio de dados ambientais (temperatura e umidade) em tempo real. Utilizando a conectividade sem fio do microcontrolador **ESP32-C3**, os dados coletados pelo sensor são transmitidos via Wi-Fi para monitoramento remoto contínuo.

## 🧰 Componentes Utilizados

- **ESP32-C3**: Microcontrolador compacto de baixo consumo energético, baseado na arquitetura RISC-V, com suporte nativo a Wi-Fi e Bluetooth 5[cite: 1].
- **Sensor de Temperatura e Umidade (DHT11 ou DHT22)**: Responsável por realizar as medições físicas do ambiente[cite: 1].
- **Protoboard**: Placa de ensaio para montagem e interconexão dos componentes sem necessidade de solda[cite: 1].
- **Jumpers (Macho-Macho / Macho-Fêmea)**: Cabos condutores para as conexões elétricas[cite: 1].
- **Cabo USB**: Utilizado para alimentação do circuito e gravação do código no ESP32-C3 via IDE Arduino[cite: 1].
